Cenário Real Inteli

🏢 SecurInteli (Fintech de Pagamentos Digitais) | Engenharia de Autenticação e Espaço Amostral de Chaves

Você é engenheiro de segurança na SecurInteli, responsável pela arquitetura do novo gateway de pagamentos. O sistema exige duas camadas de segurança criptográfica:

  1. Uma chave de API rápida de 6 caracteres alfanuméricos gerada para conexões de microserviços.
  2. Um hash de auditoria interno com 8 algarismos decimais em ordem estritamente não-decrescente (ex.: 00124789), utilizado para rastrear lotes no ledger da empresa.
A diretoria técnica precisa saber a probabilidade de colisão e o tamanho do espaço amostral de chaves válidas sob restrições para dimensionar ataques de força bruta.

Núcleo Conceitual

Combinatória no Inteli não é memorização de fórmulas isoladas: é modelagem de restrições em sistemas digitais. A regra primordial é identificar se a ordem dos elementos importa (Permutações/Arranjos) ou se a ordem é indiferente/pré-fixada (Combinações simples ou com repetição).

Princípio Fundamental da Contagem (PFC)

Se uma decisão A pode ser tomada de n maneiras e, para cada uma, uma decisão B de m maneiras, o total de pares ordenados de decisões é n × m.

Nota lateral: PFC é o algoritmo base: trace traços para cada posição restrita antes de aplicar permutações prontas.

Hashes com Ordem Fixada (Stars and Bars)

Quando um conjunto de dígitos deve ser organizado em ordem não-decrescente (crescente ou repetido), escolher o número equivale a escolher quantas vezes cada algarismo aparece, gerando uma equação com inteiros não-negativos.

Nota lateral: Problema real do Vestibular Adaptativo 2025.1 do Inteli (Trilha Avançada, Padrão 5).
📌 Fórmulas de Bolso para o Vestibular Inteli
Arranjos Simples (Ordem importa, sem repetição):
$$A(n, k) = \frac{n!}{(n - k)!}$$
Combinações Simples (Ordem não importa):
$$C(n, k) = \frac{n!}{k!(n - k)!}$$
Combinação com Repetição (Partição de Inteiros):
$$CR(n, k) = C(n + k - 1, k) = \frac{(n + k - 1)!}{k!(n - 1)!}$$
💡 Dica de Ouro: Se a ordem foi imposta pelo enunciado (ex.: "dígitos em ordem crescente"), NÃO multiplique por permutações! A ordem já consumiu o grau de liberdade.

⚠️ Armadilha Típica do Inteli: Confundir Ordem Fixada com Arranjo

No problema dos hashes de 8 algarismos em ordem não-decrescente, o candidato apressado calcula 10^8 (todas as permutações) ou arranjo A(10, 8). O correto é Combinação com Repetição CR(10, 8) = C(17, 8) = 24.310 combinações.

Prática de Recuperação Ativa (Retrieval Practice)

Responda às questões abaixo sem consultar materiais. O feedback é instantâneo e calibrado com os distratores da banca Inteli.

Questão 1 de 2

A SecurInteli gera uma chave de API provisória de 4 caracteres. O primeiro caractere DEVE ser uma letra maiúscula do alfabeto latino (26 opções), e os 3 caracteres seguintes devem ser algarismos decimais distintos (0 a 9). Quantas chaves únicas atendem rigorosamente a essa especificação?

🔍 Resolução Oficial Comentada
Resolução Passo a Passo:
1. Modelamos o token em 4 posições: [_] [_] [_] [_].
2. A 1ª posição exige uma letra maiúscula: 26 possibilidades.
3. A 2ª posição exige qualquer algarismo decimal: 10 possibilidades (0 a 9).
4. A 3ª posição exige um algarismo distinto do anterior: 9 possibilidades.
5. A 4ª posição exige um algarismo distinto dos dois anteriores: 8 possibilidades.
6. Pelo Princípio Fundamental da Contagem: 26 × 10 × 9 × 8 = 18.720 chaves válidas.
Questão 2 de 2

(Vestibular Adaptativo Inteli 2025.1 - Trilha Avançada) Um algoritmo gera um hash identificador de comprimento 8 composto exclusivamente pelos algarismos decimais {0, 1, 2, ..., 9}, com a restrição de que os algarismos devem aparecer sempre em ordem não-decrescente (exemplo: 00114789). Quantos hashes distintos esse algoritmo é capaz de gerar?

🔍 Resolução Oficial Comentada
Resolução Passo a Passo:
1. Seja x_i a quantidade de vezes que o algarismo i ∈ {0, 1, ..., 9} aparece no hash de tamanho 8.
2. Como os algarismos obrigatoriamente aparecerão agrupados em ordem não-decrescente, um hash fica completamente determinado assim que decidimos as frequências x_0, x_1, ..., x_9.
3. A soma das ocorrências deve totalizar 8: x_0 + x_1 + ... + x_9 = 8 com x_i ≥ 0.
4. O número de soluções inteiras não-negativas de uma equação com n = 10 variáveis e soma k = 8 é dado por Combinação com Repetição:
CR(10, 8) = C(10 + 8 - 1, 8) = C(17, 8) = 17! / (8! × 9!) = 24.310.
